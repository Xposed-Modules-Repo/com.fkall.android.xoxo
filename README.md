# fkall｜微信密友隐藏与 AI 助手模块

**密友隐私管理 · AI 聊天助手 · Agent 工作台 · 文档处理 · 主题美化**

在微信中管理密友隐藏与消息提醒，为指定好友、群聊配置 AI 助手，也能通过独立工作台完成资料查询、文档编辑、图片与视频创作、语音交互等任务。

## 🚀 快速使用指南

1. **安装并启用模块**：安装 `fkall`，在框架中启用该模块。
2. **关闭 API 调用保护**  
   > 务必关闭 **Xposed API 调用保护**，否则模块无法正常工作。
3. **设置作用域**：在模块作用域中勾选 **微信**。
4. **重启并激活**：强制停止微信后重新打开，按页面提示完成试用或激活。
5. **等待适配完成**：按照提示完成适配，然后再次重启微信。
6. **进入模块设置**：点击微信主界面右上角搜索，输入默认指令 **`#xoxo`**。

进入后可按需配置密友、AI 和外观功能。模块启动指令可在设置中修改。

## 🛡️ 密友隐藏与管理

- **密友名单管理**：支持导入、管理好友及群聊，查看密友未读状态。
- **默认与独立配置**：可使用统一默认规则，也可为单个密友单独配置隐藏和提醒方式。
- **会话与聊天记录隐藏**：按配置隐藏密友会话及相关聊天记录。
- **多场景名单隐藏**：支持联系人、转发、选择好友、最近联系人、标签、创建群聊等列表中的密友隐藏，以及相关搜索记录隐藏。
- **朋友圈隐藏**：按密友规则隐藏朋友圈动态、评论和点赞。
- **红点与未读隐藏**：支持隐藏主页小红点，以及未读消息列表中的密友。
- **主页会话伪装**：可将密友会话显示为选定公众号的外观。
- **消息提醒**：支持密友未读提示、来消息振动及微信团队消息形式的提醒。
- **通话与通知拦截**：按需拦截密友语音通话、视频通话和消息通知。
- **临时解除隐藏**：支持临时解除密友、聊天记录、朋友圈及转发列表隐藏；转发列表可配置长按或连续点击触发，退出相关页面后恢复隐藏。
- **快捷入口**：支持自定义打开密友列表的指令，以及长按通讯录进入密友列表。

## 💬 AI 好友与群聊助手

- **AI 白名单管理**：为指定好友或群聊启用 AI 能力，分别配置使用范围。
- **自动回复**：根据配置自动生成并回复消息。
- **AI 接管 / 回复助手**：生成候选回复，支持重新生成，再由用户选择发送。
- **上下文与记忆**：配置对话上下文、提示词和记忆，支持清理记忆与聊天缓存。
- **模型与接口配置**：支持接口地址、API Key 和模型设置，以及模型查询、配置保存和连通测试。
- **群聊管理**：支持违规检测、违规统计及踢人处理，相关操作需具备相应群管理权限。

## 🧠 独立 Agent 工作台

- 支持多轮对话、会话历史和上下文管理；可按模型能力调整思考设置。
- 支持流式回复，展示 Markdown、表格和代码块，并提供内容复制。
- **联网搜索**：搜索公开网页，读取网页正文、表格及来源链接。
- **学术检索**：查询文献题名、作者、期刊、DOI，以及可用的摘要和全文链接。
- **日常查询**：查询时间、时区、天气与天气预报。
- **数据查询**：支持参考汇率换算，以及 A 股、港股、美股行情查询。
- **确认后分享**：工作台向微信发送文字、图片、视频或文档前会先请求确认，再由用户选择接收会话。

> 查询结果以数据来源及更新时间为准。参考汇率和行情快照不等同于无延迟交易报价；文献检索不保证提供免费全文。

## 📄 Word / Excel / PowerPoint 文档处理

- **创建文档**：通过自然语言新建 Word 文档、Excel 工作簿和 PowerPoint 演示文稿。
- **读取与编辑**：导入现有文档，按需修改文字、段落、表格、单元格、公式及幻灯片内容与版式。
- **撤销与重做**：支持当前文档的编辑版本回退与重做。
- **聊天文件导入**：长按已下载的微信文件消息，选择「添加到 Agent 工作台」。
- **导出与分享**：编辑后导出文档，或确认后分享给好友、群聊；聊天原文件不会被直接覆盖。

> 主要支持 DOCX、XLSX、PPTX 等现代 Office 格式。该文档工作流不包含 PDF 或旧版 DOC、XLS、PPT 编辑支持。

## 🎨 AI 图片与视频创作

- **文字生图**：根据提示词生成图片。
- **图片编辑**：对已有图片进行修改、重绘和风格化处理。
- **多图合成**：将多张参考图片融合为一张新图片。
- **视频生成**：支持文生视频、单图生成视频，以及按顺序排列多张图片生成关键帧过渡视频。
- 生成结果可在工作台中查看，并在确认后选择微信接收会话发送。

## 🎙️ 语音 Live 与语音创作

- **语音 Live**：在工作台中与 AI 进行语音交互，支持麦克风静音、打断回复及结束会话。
- **语音设置**：可配置语音方案，并按需使用自定义语言模型。
- **文字转语音**：输入文本生成语音，支持文本优化与表达风格设置。
- **多种音色方式**：支持预置音色、音色设计和声音复刻，可导入或录制自有、已获授权的音色样本。
- **试听、保存与发送**：生成后可试听、保存到本地，或选择微信接收会话发送。

## 🖌️ 微信主题与聊天气泡

- **六套主题预设**：流光玻璃、云雾蓝、青瓷、暮紫、萌爪乐园、日漫分镜。
- **明暗模式**：支持跟随微信明暗状态（无法取得时参考系统），也可指定浅色或深色。
- **自定义配色与布局**：调整主题颜色、圆角、底栏不透明度及底栏离底距离。
- **自定义背景**：分别设置主页和聊天背景图片。
- **自定义底栏图标**：为四个页签设置普通、选中状态图标。
- **聊天气泡**：可独立选择气泡样式，也可让气泡跟随主题材质与配色。
- **预览与恢复**：修改后预览、应用，也可关闭主题，恢复微信原生主题外观。

> 主题仅改变本机外观，主要作用于已适配的界面；气泡样式适用于文字和普通语音，不替换头像、图片、视频、红包或转账卡片。玻璃等效果受设备和系统渲染能力影响。
