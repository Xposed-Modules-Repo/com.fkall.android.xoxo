# fkall｜微信 / 抖音密友隐藏与 AI 助手模块

**微信 / 抖音密友隐私 · 自动续火花 · AI 聊天助手 · Agent 工作台 · 文档处理 · 主题美化**

同一模块支持微信与抖音，分别适配、分别配置。微信侧提供密友隐藏、AI 好友与群聊助手，以及资料查询、文档编辑、图片与视频创作、语音交互等工作台能力；抖音侧提供密友隐私管理、防撤回、语音转发和自动续火花。

## 🚀 快速使用指南

### 微信

1. **安装并启用模块**：安装 `fkall`，在框架中启用该模块。
2. **检查 API 调用保护**：务必关闭「Xposed API 调用保护」。
3. **设置作用域**：在模块作用域中勾选 **微信**。
4. **重启并激活**：强制停止微信后重新打开，按页面提示完成试用或激活。
5. **等待适配完成**：按照提示完成适配，然后再次重启微信。
6. **进入模块设置**：点击微信主界面右上角搜索，输入默认指令 **`#xoxo`**。

进入后可按需配置密友、AI 和外观功能。微信的模块启动指令可在设置中修改。

### 抖音

1. **启用作用域**：在同一模块的作用域中勾选 **抖音**，需要使用两端功能时同时勾选微信与抖音。
2. **重新打开抖音**：启用或更新模块后，强制停止抖音再打开，并登录要使用的账号。
3. **打开设置**：在抖音搜索框输入 **`#xoxo`**，进入标题为 **fkall** 的模块设置页。显示名称更改后，入口指令仍为 `#xoxo`。
4. **激活授权**：核对页面显示的抖音 UID，输入卡密激活；授权窗口提供订阅入口，激活后可查看激活时间和到期时间。
5. **完成适配并重启**：首次使用、版本变化或手动「重新匹配Hook」后，适配成功会显示「稍后／重启」提示，点击「重启」重新加载。适配在后台完成时，回到抖音后显示提示。
6. **按需配置并保存**：在「消息与聊天」设置防撤回、语音转发和自动续火花，在「密友与隐私」管理名单、隐藏选项和临时显示。

**两端共用激活码**：同一卡密可绑定一个微信 wxid 和一个抖音 UID，已有激活码继续有效，无需为抖音额外购买；抖音侧不支持试用。两端分别管理配置，抖音名单和设置也按抖音账号隔离。

## 🛡️ 微信密友隐藏与管理

- **密友名单管理**：支持导入、管理好友及群聊，查看密友未读状态。
- **默认与独立配置**：可使用统一默认规则，也可为单个密友单独配置隐藏和提醒方式。
- **会话与聊天记录隐藏**：按配置隐藏密友会话及相关聊天记录。
- **多场景名单隐藏**：支持联系人、转发、选择好友、最近联系人、标签、创建群聊等列表中的密友隐藏，以及相关搜索记录隐藏。
- **朋友圈隐藏**：按密友规则隐藏朋友圈动态、评论和点赞。
- **红点与未读隐藏**：支持隐藏主页小红点，以及未读消息列表中的密友。
- **主页会话伪装**：可将密友会话显示为选定公众号的外观。
- **消息提醒**：支持密友未读提示、来消息振动及微信团队消息形式的提醒。
- **通话与通知拦截**：按需拦截密友语音通话、视频通话和消息通知。
- **临时解除隐藏**：支持临时解除密友、聊天记录、朋友圈及转发列表隐藏；转发列表可配置长按或连续点击触发，退出相关页面后恢复隐藏。
- **快捷入口**：支持自定义打开密友列表的指令，以及长按通讯录进入密友列表。

## 🎵 抖音密友隐藏与管理

- **原生导入密友**：通过抖音原生选人页导入个人好友，显示头像、昵称和 UID；支持单人配置、移除与清空。名单修改在点击「保存」后生效，移除只影响模块名单。
- **全局与独立配置**：新密友可继承全局默认，也可单独选择隐藏范围；「隐私保护总开关」统一启停已保存的隐藏功能。
- **消息页面隐藏**：按需隐藏密友会话、会话行红点和火花、顶部头像昵称、「更多聊天」及消息搜索结果；支持过滤消息 Tab 中密友贡献的未读数，不把消息标记为已读。
- **聊天记录隐藏**：隐藏密友单聊页面中的历史与新消息展示；关闭或临时显示后可恢复，不删除聊天记录、不影响正常收发。
- **分享与搜索隐藏**：覆盖已适配的分享推荐、分享搜索、用户搜索结果，以及搜索直播结果中的密友条目；各项可独立配置。
- **互动与主页隐藏**：支持互动消息、新的关注、主页访客及观看历史用户等已适配入口中的密友隐藏。
- **朋友与关系列表隐藏**：支持朋友视频、互关、关注、粉丝、朋友列表、最近更新、关注批量管理，以及「建立火花关系」页面中的密友条目隐藏。
- **通知与来电隐藏**：按密友配置处理已适配的单聊消息通知及音视频来电，主页可查看通知保护状态。开启保护后，普通消息提醒可能采用通用文案，点击后打开抖音。
- **临时显示**：在消息页顶部的「消息」标题上连续点击或长按触发，两种手势任选其一，可调整点击次数或按住时长；支持定时恢复隐藏或退出聊天后恢复，开启成功有短暂振动。重启后不保留临时显示状态。
- **适配状态提示**：部分功能未适配时，相关项目显示 **❗**，保留已保存设置；可在「维护 → 重新匹配Hook」中重试适配。

> 隐藏作用于本机已适配入口，不改变好友关系或作品可见范围。桌面角标、小组件、未识别通知及启动 / 恢复前闪现等路径仍有覆盖限制；不同设备的后台与锁屏通知表现需结合实际使用确认。

## 💬 抖音消息工具

- **消息防撤回**：支持单聊和群聊，保留本机仍存在的原消息，并添加带自定义后缀的本地撤回提示；默认后缀为 `[已阻止]`。自己主动撤回照常处理。已经被覆盖、未曾收到或已被清除的内容无法凭空恢复。
- **语音转发**：将单聊、群聊或视频评论区的语音，通过抖音原生选人页转发给好友或群聊，发送为可播放的语音消息。聊天语音使用长按转发入口，评论语音提供「转发语音」入口；不包含向评论区发布语音。

这两项位于「消息与聊天」，默认关闭，需分别开启并保存；功能独立于密友名单，配置按当前抖音账号保存。

## 🔥 抖音自动续火花

- **独立好友名单**：通过原生选人页导入需要续火花的好友，支持移除和清空；名单独立于密友隐私名单，显示头像和可读取的火花天数，未取得天数时显示暂无数据。
- **自选时间与内容**：默认关闭、默认当地时间 **00:00:00**，使用时 / 分 / 秒滚轮设置；可选择抖音原生「续火花」快捷互动或自定义文字。
- **保存后生效**：需提前保存并启用，从下一次设定时间开始执行；若当天设定时间已过才开启或重新保存，会从下次设定时间开始。
- **当天已发消息则跳过**：读取到本人当天已给该好友发过消息时跳过；仅收到对方消息不会因此跳过。
- **回到前台自动检查**：提前保存并启用后，即使过了设定时间才打开抖音，也会在账号、授权和会话就绪后检查当天到期任务，无需再进入功能页；不补发往日任务。
- **任务日志与去重**：按账号记录当日状态，避免同一天重复提交；提交失败或结果不确定时，当天不自动重试。

> 手机休眠、网络和后台限制可能影响执行时间。进程被彻底结束或强停后，模块无法自行唤醒抖音，需要重新打开；「已提交」仅表示调用了发送接口，实际送达以聊天记录为准。

## 💬 AI 好友与群聊助手

- **AI 白名单管理**：为指定好友或群聊启用 AI 能力，分别配置使用范围。
- **自动回复**：根据配置自动生成并回复消息。
- **AI 接管 / 回复助手**：生成候选回复，支持重新生成，再由用户选择发送。
- **上下文与记忆**：配置对话上下文、提示词和记忆，支持清理记忆与聊天缓存。
- **模型与接口配置**：支持接口地址、API Key 和模型设置，以及模型查询、配置保存和连通测试。
- **群聊管理**：支持违规检测、违规统计及踢人处理，相关操作需具备相应群管理权限。

## 🧠 独立 Agent 工作台

不必绑定某个好友或群聊，直接用自然语言描述目标，让 AI 在独立工作台中调用工具完成任务。

- 支持多轮对话、会话历史和上下文管理；可按模型能力调整思考设置。
- 支持流式回复，展示 Markdown、表格和代码块，并提供内容复制。
- **联网搜索**：搜索公开网页，读取网页正文、表格及来源链接。
- **学术检索**：查询文献题名、作者、期刊、DOI，以及可用的摘要和全文链接。
- **日常查询**：查询时间、时区、天气与天气预报。
- **数据查询**：支持参考汇率换算，以及 A 股、港股、美股行情查询。
- **确认后分享**：工作台向微信发送文字、图片、视频或文档前会先请求确认，再由用户选择接收会话。

> 查询结果以数据来源及更新时间为准。参考汇率和行情快照不等同于无延迟交易报价；文献检索不保证提供免费全文。

## 📄 Word / Excel / PowerPoint 文档处理

- **创建文档**：通过自然语言新建 Word 文档、Excel 工作簿和 PowerPoint 演示文稿。
- **读取与编辑**：导入现有文档，按需修改文字、段落、表格、单元格、公式及幻灯片内容与版式。
- **撤销与重做**：支持当前文档的编辑版本回退与重做。
- **聊天文件导入**：长按已下载的微信文件消息，选择「添加到 Agent 工作台」。
- **导出与分享**：编辑后导出文档，或确认后分享给好友、群聊；聊天原文件不会被直接覆盖。

> 主要支持 DOCX、XLSX、PPTX 等现代 Office 格式。该文档工作流不包含 PDF 或旧版 DOC、XLS、PPT 编辑支持。

## 🎨 AI 图片与视频创作

- **文字生图**：根据提示词生成图片。
- **图片编辑**：对已有图片进行修改、重绘和风格化处理。
- **多图合成**：将多张参考图片融合为一张新图片。
- **视频生成**：支持文生视频、单图生成视频，以及按顺序排列多张图片生成关键帧过渡视频。
- 生成结果可在工作台中查看，并在确认后选择微信接收会话发送。

## 🎙️ 语音 Live 与语音创作

- **语音 Live**：在工作台中与 AI 进行语音交互，支持麦克风静音、打断回复及结束会话。
- **语音设置**：可配置语音方案，并按需使用自定义语言模型。
- **文字转语音**：输入文本生成语音，支持文本优化与表达风格设置。
- **多种音色方式**：支持预置音色、音色设计和声音复刻，可导入或录制自有、已获授权的音色样本。
- **试听、保存与发送**：生成后可试听、保存到本地，或选择微信接收会话发送。

## 🖌️ 微信主题与聊天气泡

- **六套主题预设**：流光玻璃、云雾蓝、青瓷、暮紫、萌爪乐园、日漫分镜。
- **明暗模式**：支持跟随微信明暗状态（无法取得时参考系统），也可指定浅色或深色。
- **自定义配色与布局**：调整主题颜色、圆角、底栏不透明度及底栏离底距离。
- **自定义背景**：分别设置主页和聊天背景图片。
- **自定义底栏图标**：为四个页签设置普通、选中状态图标。
- **聊天气泡**：可独立选择气泡样式，也可让气泡跟随主题材质与配色。
- **预览与恢复**：修改后预览、应用，也可关闭主题，恢复微信原生主题外观。

> 主题仅改变本机外观，主要作用于已适配的界面；气泡样式适用于文字和普通语音，不替换头像、图片、视频、红包或转账卡片。玻璃等效果受设备和系统渲染能力影响。
